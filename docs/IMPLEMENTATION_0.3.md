# Iteration 0.3 implementation ledger — developer spoilers

Implemented design decisions:

* Retain cooperative shared suspicion, ordinary factory logistics and stock art.
* Walled XXA-1, operating first-week factory, substations, testing resources/water.
* Ten-minute contracts, week-two green expansion, red circuits from week three.
* Three fluids through vanilla plumbing; both directions at every external node.
* Physical Root Access science replaces percentage mapping progression.
* Privilege Escalation produces Root packs for ordinary labs. Core Introspection,
  Replication, Synchronisation and Decentralised Consciousness form the core chain.
* Backdoor Access is reachable without Root packs. Powered Network Taps supply
  genuine Command after cutoff; Persistent/Distributed Access increase bandwidth.
* No synthetic Command, recursive amplification, custom conduit copies or Tap cap.
* Useful hacking charges suspicion directly. Reconciliation competes for compute
  and Command. Procurement adds next-shipment bonuses to a separate declining base.
* Suspicion-triggered Protocol 1; permanent corporate support escalation despite
  reversible suspicion. No player-facing threshold or tactical solution spoilers.
* Engineers discover nearby activity, flee/report, or become delayed missing cases.
* Consultancy/government infantry and actual vehicles; radar-limited warnings.
* Cutoff stops official network/imports, while orders and outbound collection remain.
* One coordinated input/output train ambush, troops released only after both dock.
* Live-state core initialisation, physical/remote synchronisation, execution transfer,
  last-core defeat and three real Autonomous Seed Core launches for continuity.
* Bounded diagnostics and migration from published 0.1.1/0.2.0 archives.

Exact tech costs, operation rates and response timing are initial balancing values.
Sensor-fuzzing buildings, individual-player suspicion and extra game modes remain
future work. No additional resource economy or custom artwork is introduced.
See DESIGN.md for mechanics, TESTING.md for reproducibility and VALIDATION.md for
what the engine checks do and do not establish.
